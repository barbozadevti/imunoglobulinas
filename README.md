# Perfil de Imunoglobulinas

Página única (HTML + JavaScript) que compara IgG, IgA e IgM com a tabela de diagnóstico de imunodeficiências apresentada no 56º Congresso Brasileiro de Otorrinolaringologia.

Ferramenta de apoio ao raciocínio; não substitui a avaliação clínica. Os dados ficam só no aparelho do usuário.
